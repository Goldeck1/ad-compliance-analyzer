# 🎯 Анализатор рекламы с GigaChat

Система для автоматического поиска нарушений законодательства РФ в рекламных текстах.

---

## 📊 Данные обучения

GigaChat обучен на **1498 документах**:
- **335** примеров нарушений (dataset/train.xlsx)
- **1149** статей законов РФ (data/regulations.json)
  - ФЗ № 38 "О рекламе": 108 статей
  - ФЗ № 135 "О защите конкуренции": 190 статей
  - ФЗ № 152 "О персональных данных": 69 статей
  - Уголовный кодекс РФ: 757 статей
  - Другие законы и разъяснения: 25 статей
- **14** корпусов законов и методических материалов (data/laws_corpus.json)
  - Буклеты, промты, чек-листы ФАС
  - Полные тексты документов

## 📤 Формат вывода

Вывод соответствует колонкам Excel файла `train.xlsx`. **Все данные в одном JSON объекте.**

### Нет нарушений:

```json
{
  "violation_status": "Нет",
  "law": "",
  "article": "",
  "article_name": "",
  "description": "Нарушений не обнаружено",
  "risk": "",
  "recommendation": "",
  "original_text": "Участвуйте в розыгрыше..."
}
```

### Одно нарушение:

```json
{
  "violation_status": "Да",
  "law": "ФЗ № 38 'О рекламе'",
  "article": "22",
  "article_name": "Особенности рекламы алкогольной продукции",
  "description": "Реклама алкоголя запрещена в интернете согласно ч.2 ст.22",
  "risk": "Штраф для юр.лиц: 100 000 - 500 000 руб. (ст. 14.3 КоАП)",
  "recommendation": "Удалить рекламу алкоголя из интернет-канала",
  "original_text": "Купите французское вино..."
}
```

### Несколько нарушений (перечисление через "; "):

```json
{
  "violation_status": "Да",
  "law": "ФЗ № 38 'О рекламе'; ФЗ № 152 'О персональных данных'",
  "article": "9; 7",
  "article_name": "Особенности рекламы стимулирующих лотерей; Обработка персональных данных",
  "description": "Запрещена реклама стимулирующих лотерей с условием покупки без полных правил; Запрещён сбор данных без согласия",
  "risk": "Штраф: 100 000 - 500 000 руб. (ст. 14.3 КоАП); Штраф: 50 000 - 75 000 руб. (ст. 13.11 КоАП)",
  "recommendation": "Указать полные правила розыгрыша; Добавить форму согласия на обработку ПД",
  "original_text": "Купи товар и выиграй приз! Оставь свой email..."
}
```

**Поля соответствуют колонкам Excel:**
- `violation_status` ➜ "Есть нарушение (Да/Нет/Потенциальное нарушение)"
- `law` ➜ "Закон" (несколько через "; ")
- `article` ➜ "Статья" (несколько через "; ")
- `article_name` ➜ "Название статьи" (несколько через "; ")
- `description` ➜ "Выдержка/описание" (несколько через "; ")
- `risk` ➜ "Риск" (несколько через "; ")
- `recommendation` ➜ "Рекомендации" (несколько через "; ")

## ✏️ Как использовать

Откройте `analyzer.ipynb` в Jupyter Notebook и выполните ячейки последовательно:

1. **Блок 1**: Подключение к GigaChat
2. **Блок 2**: Обучение на данных
3. **Блок 3**: Тестирование

Добавьте свой текст в последнюю ячейку и запустите её!

## 🔍 Категории нарушений

1. **ФЗ № 38 "О рекламе"** (218 примеров)

   - Реклама алкоголя
   - Реклама БАД с лечебными обещаниями

   - Недобросовестная конкуренция

   - Призывы к незаконным действиям
